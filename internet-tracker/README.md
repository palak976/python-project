💼 Internship Tracker

A beginner-friendly Python project that helps you manage and track your internship applications through a simple web interface.

Features:

- Add Applications: Save company names, job roles, and application statuses.
- View Dashboard: Track the total number of applications, applied positions, and interested companies.
- Filter Applications: View applications based on their status.
- Update Applications: Edit company names, roles, and statuses.
- Delete Applications: Remove applications when needed.
- Data Persistence: Save application details in a JSON file.

Built With:

- Python
- Streamlit
- JSON

How to Run:

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install Streamlit if you haven't already:
   py -3.13 -m pip install streamlit

4. Start the application:
   py -3.13 -m streamlit run ui.py

5. Open the local URL displayed in your terminal.
